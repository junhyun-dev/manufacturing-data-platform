내 CSV는 어떤 형식이어야 하나요?

한 행에 하나의 관측값을 넣으세요. 필수 열은 아래 다섯 개이며, 선택 열 quality에는 good, uncertain, bad, unspecified를 사용할 수 있습니다.

timestamp,equipment,tag,value,unit

2026-01-01T09:00:10,APU-1,Oil_temperature,53.7,°C

시간대가 있는 시각과 없는 시각을 한 파일에서 섞지 마세요. 같은 설비·항목·시각의 중복 행이나 한 항목 안의 단위 변경은 허용하지 않습니다. 품질을 생략하면 ‘미제공’으로 표시됩니다.

    최근 검사 기록

      같은 원본의 재검사로 파일 내용이 수정되지는 않습니다.

      샘플 체험전달이 누락되면 결과는 어떻게 되나요?

      공개 샘플의 일부 행을 의도적으로 전달하지 않는 체험입니다. 최근 검사는 ‘전달 미완료’로 바뀌고 기존 결과는 유지됩니다. 보관된 전체 원본으로 복구하면 같은 버전으로 돌아옵니다.

      실제 센서 결측이나 네트워크 장애를 진단·복구하는 기능은 아닙니다.
